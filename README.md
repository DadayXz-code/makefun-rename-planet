One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters. This entry renames Jupiter "The Bouncer" — it has spent 4 billion years swallowing asteroids so Earth doesn't have to. The name is earned by Jupiter's own trait: its gravity pulls in asteroids and comets that might otherwise hit Earth. `main.py` (Python 3.13, standard library only) writes the line to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat ./output/entry.txt
```

The program is deterministic: every run writes the same 106-character line, and it writes nothing outside the output directory.
